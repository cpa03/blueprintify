# Documentation Archive

This directory contains archived documentation that has been superseded by newer versions.

## Contents

- `plan-2026-01-07.md` - Original product plan and architecture document (Draft status). 
  - **Superseded by**: `docs/roadmap.md`
  - **Reason**: Roadmap is actively maintained and reflects current M1/M2/M3 milestone progress

## Archive Policy

Documents are archived when:
1. They are marked as "Draft" and superseded by finalized documentation
2. They contain outdated information that could confuse current development
3. They represent early planning phases that have evolved significantly

Archived documents are retained for historical reference but should not be used for current development decisions.
