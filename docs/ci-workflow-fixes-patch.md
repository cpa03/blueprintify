## Fix 3: Health Check Failure Detection — pr-gatekeeper.yml

**File:** `.github/workflows/pr-gatekeeper.yml`

**Root cause:** The old pattern `cmd > log 2>&1 || echo "Failed"` masked failures because:
- `|| echo` always exits with code 0 (`echo` always succeeds), so the step never actually failed
- Subsequent `grep -q "Failed" *.log` relied on error messages containing "Failed" literally — TypeScript/lint output rarely does

**Fix:** Use proper exit code capture (standard bash pattern):

```diff
- npm run typecheck > typecheck.log 2>&1 || echo "Typecheck Failed"
- npm run lint > lint.log 2>&1 || echo "Lint Failed"
- npm run build > build.log 2>&1 || echo "Build Failed"
+ set +e
+ npm run typecheck > typecheck.log 2>&1; TYPE_CHECK=$?
+ npm run lint > lint.log 2>&1; LINT_CHECK=$?
+ npm run build > build.log 2>&1; BUILD_CHECK=$?

- if grep -q "Failed" typecheck.log || grep -q "Failed" lint.log || grep -q "Failed" build.log; then
+ if [ $TYPE_CHECK -ne 0 ] || [ $LINT_CHECK -ne 0 ] || [ $BUILD_CHECK -ne 0 ]; then
     echo "Health check failed. Engaging Debugger."
     echo "status=fail" >> $GITHUB_OUTPUT
     exit 1
```
