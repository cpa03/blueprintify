## ⚠️ Constraint: GITHUB_TOKEN Permissions

The CI GITHUB_TOKEN (`github-actions[bot]`) lacks `issues: write` and `workflows: write` permissions:

- Cannot add/remove/update issue labels
- Cannot add comments or close issues
- Cannot push changes to `.github/workflows/` files

**Impact**: Label normalization and issue deduplication recommendations are documented here but cannot be applied via API. A maintainer with a PAT must apply them.
